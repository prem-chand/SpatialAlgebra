Detailed Description

Represents a single link in a kinematic chain.

The Link structure contains all necessary information for ABA:

  • Kinematic properties (parent, transform, joint axis)
  • Inertial properties (rigid body inertia)
  • State variables (position, velocity, acceleration)
  • Intermediate quantities for ABA (velocities, forces, articulated inertia)

Memory Layout: All spatial vectors use 6D representation: [angular; linear] Transforms are stored as PluckerTransform (rotation + translation)

Note
Parent index -1 indicates the base link (no parent)
