\doxysubsection{Detailed Description}
Implementation of Articulated Body Algorithm (ABA) for forward dynamics. 

This file implements the core ABA recursive algorithms\+:
\begin{DoxyItemize}
\item outward\+Pass()\+: velocity propagation and bias acceleration
\item inward\+Pass()\+: articulated inertia accumulation and force propagation
\item compute\+Accelerations()\+: main solver combining both passes
\end{DoxyItemize}

The implementation follows Featherstone (2008) Algorithm 7.\+3 with O(n) computational complexity for serial chains.
