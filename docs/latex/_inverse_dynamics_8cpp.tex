\doxysubsection{Detailed Description}
Implementation of Recursive Newton-\/\+Euler Algorithm (RNEA) for inverse dynamics. 

This file implements the core RNEA recursive algorithms\+:
\begin{DoxyItemize}
\item outward\+Pass()\+: velocity and acceleration propagation
\item inward\+Pass()\+: force propagation and torque computation
\item compute\+Torques()\+: main solver combining both passes
\end{DoxyItemize}

The implementation follows Featherstone (2008) Algorithm 7.\+1 with O(n) computational complexity for serial chains.
