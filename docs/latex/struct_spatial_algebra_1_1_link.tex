\doxysubsection{Detailed Description}
Represents a single link in a kinematic chain. 

The \doxylink{struct_spatial_algebra_1_1_link}{Link} structure contains all necessary information for ABA\+:
\begin{DoxyItemize}
\item Kinematic properties (parent, transform, joint axis)
\item Inertial properties (rigid body inertia)
\item State variables (position, velocity, acceleration)
\item Intermediate quantities for ABA (velocities, forces, articulated inertia)
\end{DoxyItemize}

Memory Layout\+: All spatial vectors use 6D representation\+: \mbox{[}angular; linear\mbox{]} Transforms are stored as \doxylink{class_spatial_algebra_1_1_plucker_transform}{Plucker\+Transform} (rotation + translation)

\begin{DoxyNote}{Note}
Parent index -\/1 indicates the base link (no parent) 
\end{DoxyNote}
