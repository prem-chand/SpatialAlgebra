\doxysubsection{Detailed Description}
Inverse dynamics solver using Recursive Newton-\/\+Euler Algorithm. 

The \doxylink{class_spatial_algebra_1_1_inverse_dynamics}{Inverse\+Dynamics} class implements Featherstone\textquotesingle{}s RNEA (Algorithm 7.\+1) for efficient O(n) computation of joint torques. The algorithm handles both serial chains and branching kinematic trees.

Algorithm Complexity\+:
\begin{DoxyItemize}
\item Time\+: O(n) where n is the number of links
\item Space\+: O(n) for storing link states
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Setup kinematic tree by populating links vector
\item Set joint states (q, qdot, qddot)
\item Call compute\+Torques(qddot) to solve for joint torques
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Links must be ordered such that parents appear before children 

For branching trees, all children of a link must have consecutive indices 
\end{DoxyNote}
