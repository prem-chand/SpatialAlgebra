\doxysubsection{Detailed Description}
Base class for spatial vectors in 6D space. 

The \doxylink{class_spatial_algebra_1_1_spatial_vector}{Spatial\+Vector} class implements the fundamental operations for 6D spatial vectors used in rigid body dynamics. It serves as the base class for both \doxylink{class_spatial_algebra_1_1_motion_vector}{Motion\+Vector} (twists) and \doxylink{class_spatial_algebra_1_1_force_vector}{Force\+Vector} (wrenches) classes.

Mathematical Properties\+:
\begin{DoxyItemize}
\item Dimension\+: 6 (3 for angular + 3 for linear)
\item Addition forms a vector space
\item Cross products follow special rules for motion/force duality
\end{DoxyItemize}

Implementation Notes\+:
\begin{DoxyItemize}
\item Uses Eigen\+::\+Vector3d for efficient 3D vector operations
\item Stores angular and linear components separately for clarity
\item Provides both motion and force cross products
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
The distinction between motion and force vectors is crucial for correct physical interpretation and operations. Use the appropriate derived class (\doxylink{class_spatial_algebra_1_1_motion_vector}{Motion\+Vector} or \doxylink{class_spatial_algebra_1_1_force_vector}{Force\+Vector}) for type safety. 
\end{DoxyWarning}
