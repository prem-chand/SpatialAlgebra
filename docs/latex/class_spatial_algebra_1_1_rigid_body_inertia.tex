\doxysubsection{Detailed Description}
Class representing the spatial inertia of a rigid body. 

The \doxylink{class_spatial_algebra_1_1_rigid_body_inertia}{Rigid\+Body\+Inertia} class provides a compact and efficient representation of rigid body inertial properties for spatial algebra computations.

Physical Properties\+:
\begin{DoxyItemize}
\item Symmetric positive definite (when physically valid)
\item Transforms covariantly under coordinate changes
\item Maps motion vectors to force vectors
\end{DoxyItemize}

Implementation Features\+:
\begin{DoxyItemize}
\item Stores rotational inertia in lower triangular form for efficiency
\item Provides direct access to mass, COM, and inertia components
\item Implements efficient spatial operations
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The rotational inertia is stored about the center of mass frame to minimize numerical errors and simplify transformations. 
\end{DoxyNote}
