\doxysubsection{Detailed Description}
Class representing coordinate transformations in Plücker coordinates. 

This file implements rigid body coordinate transformations using Plücker coordinates, which are essential for spatial algebra operations in robotics and multibody dynamics. These transforms combine rotation and translation in a way that preserves the dual relationship between motion and force vectors.

Mathematical Representation\+: A Plücker transform X = \mbox{[}E 0; -\/E\texorpdfstring{$\ast$}{*}r̂ E\mbox{]} where\+:
\begin{DoxyItemize}
\item E\+: 3x3 rotation matrix
\item r̂\+: 3x3 skew-\/symmetric matrix from translation vector r
\item \mbox{[}A; B\mbox{]} denotes a 6x6 block matrix
\end{DoxyItemize}

Key Properties\+:
\begin{DoxyItemize}
\item Preserves the duality between motion and force vectors
\item Forms a Lie group (SE(3)) with composition as the group operation
\item Transforms spatial quantities consistently with rigid body motion
\end{DoxyItemize}
