\doxysubsection{Detailed Description}
Forward dynamics solver using Articulated Body Algorithm. 

The \doxylink{class_spatial_algebra_1_1_forward_dynamics}{Forward\+Dynamics} class implements Featherstone\textquotesingle{}s ABA (Algorithm 7.\+3) for efficient O(n) computation of joint accelerations. The algorithm handles both serial chains and branching kinematic trees.

Algorithm Complexity\+:
\begin{DoxyItemize}
\item Time\+: O(n) where n is the number of links
\item Space\+: O(n) for storing link states
\end{DoxyItemize}

Usage Pattern\+:
\begin{DoxyEnumerate}
\item Setup kinematic tree by populating links vector
\item Set joint states (q, qdot) and external forces (f)
\item Call compute\+Accelerations(tau) to solve for qddot
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Links must be ordered such that parents appear before children 

For branching trees, all children of a link must have consecutive indices 
\end{DoxyNote}

Main entry point for forward dynamics computation. Executes the three-\/phase ABA\+:
\begin{DoxyEnumerate}
\item Outward pass\+: propagate velocities, compute bias accelerations
\item Inward pass\+: accumulate articulated inertias and bias forces
\item Solve\+: compute joint accelerations from torques
\end{DoxyEnumerate}
