\doxysubsection{Detailed Description}
Articulated Body Algorithm (ABA) for forward dynamics computation. 

This file implements Featherstone\textquotesingle{}s Articulated Body Algorithm (ABA) for computing joint accelerations from applied torques. The ABA is an O(n) recursive algorithm that efficiently solves the forward dynamics problem for serial and branching kinematic chains.

Algorithm Overview\+:
\begin{DoxyEnumerate}
\item Outward pass (base to tip)\+: Propagate velocities, compute bias accelerations
\item Inward pass (tip to base)\+: Accumulate articulated inertias, solve for accelerations
\end{DoxyEnumerate}

Mathematical Foundation\+: The ABA solves the equation\+: τ = H(q)q̈ + C(q,q̇) + G(q) where\+:
\begin{DoxyItemize}
\item H(q)\+: Joint space inertia matrix
\item C(q,q̇)\+: Coriolis and centrifugal forces
\item G(q)\+: Gravity forces (not implemented, add external forces)
\end{DoxyItemize}
