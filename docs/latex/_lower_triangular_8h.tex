\doxysubsection{Detailed Description}
Memory-\/efficient implementation of lower triangular matrices. 

This file provides a specialized implementation of lower triangular matrices optimized for both memory usage and computational efficiency. It uses a packed storage format that only stores the non-\/zero elements, making it particularly suitable for applications in spatial algebra and robotics.

Storage Format\+: For an n×n matrix, elements are stored in a 1D array in row-\/major order\+: \mbox{[} a11, a21, a22, a31, a32, a33, ... \mbox{]} Total storage\+: n(n+1)/2 elements

Performance Features\+:
\begin{DoxyItemize}
\item O(n²/2) storage instead of O(n²)
\item Implicit zeros in upper triangle
\item Open\+MP parallelization for matrix operations
\item Efficient matrix-\/vector and matrix-\/matrix products
\end{DoxyItemize}
