\doxysubsection{Detailed Description}
Class representing spatial coordinate transformations. 

The \doxylink{class_spatial_algebra_1_1_plucker_transform}{Plucker\+Transform} class implements rigid body transformations in Plücker coordinates, providing a consistent framework for transforming spatial vectors and inertias between different coordinate frames.

Mathematical Properties\+:
\begin{DoxyItemize}
\item Composition rule\+: X1 \texorpdfstring{$\ast$}{*} X2 represents sequential transforms
\item Inverse transform\+: X\texorpdfstring{$^\wedge$}{\string^}(-\/1) exists and X \texorpdfstring{$\ast$}{*} X\texorpdfstring{$^\wedge$}{\string^}(-\/1) = identity
\item Motion transform\+: v\textquotesingle{} = Xm \texorpdfstring{$\ast$}{*} v
\item Force transform\+: f\textquotesingle{} = Xf \texorpdfstring{$\ast$}{*} f = X\texorpdfstring{$^\wedge$}{\string^}(-\/T) \texorpdfstring{$\ast$}{*} f
\end{DoxyItemize}

Implementation Notes\+:
\begin{DoxyItemize}
\item Stores rotation and translation separately for efficiency
\item Provides both motion and force transformation methods
\item Handles both direct and inverse transformations
\item Supports transformation of inertia matrices
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
The translation vector represents the origin of the new frame expressed in the old frame coordinates. 
\end{DoxyWarning}
