\doxysubsection{Detailed Description}
Memory-\/efficient lower triangular matrix class. 

Implements a lower triangular matrix using packed storage format, providing both memory efficiency and fast operations. The class ensures that only the lower triangular elements are stored and modified, while upper triangular elements are implicitly zero.

Mathematical Properties\+:
\begin{DoxyItemize}
\item All elements above main diagonal are zero
\item Matrix-\/matrix product of lower triangular matrices is lower triangular
\item Transpose converts lower to upper triangular
\end{DoxyItemize}

Implementation Features\+:
\begin{DoxyItemize}
\item Packed storage format for memory efficiency
\item Bounds checking in debug mode
\item Exception safety for invalid operations
\item Open\+MP parallelization for performance 
\end{DoxyItemize}
