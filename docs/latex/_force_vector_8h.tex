\doxysubsection{Detailed Description}
Class representing spatial force vectors (wrenches) in rigid body dynamics. 

This file implements force vectors (also known as wrenches) in spatial algebra, which unify the representation of torques and forces in 3D space. Force vectors are essential for describing the complete force state acting on rigid bodies in a compact and geometrically meaningful way.

Mathematical Representation\+: A force vector f = \mbox{[}τ; f\mbox{]} consists of\+:
\begin{DoxyItemize}
\item τ\+: Torque/moment vector (N⋅m)
\item f\+: Linear force vector (N)
\end{DoxyItemize}

Physical Interpretation\+:
\begin{DoxyItemize}
\item τ represents the moment or torque around the reference point
\item f represents the linear force acting at the reference point
\item Together they form a "{}wrench"{} that completely describes force action
\end{DoxyItemize}
