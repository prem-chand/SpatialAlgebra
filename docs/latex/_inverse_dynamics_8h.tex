\doxysubsection{Detailed Description}
Recursive Newton-\/\+Euler Algorithm (RNEA) for inverse dynamics computation. 

This file implements Featherstone\textquotesingle{}s Recursive Newton-\/\+Euler Algorithm (RNEA) for computing joint torques from joint motion. The RNEA is an O(n) recursive algorithm that efficiently solves the inverse dynamics problem for serial and branching kinematic chains.

Algorithm Overview\+:
\begin{DoxyEnumerate}
\item Outward pass (base to tip)\+: Propagate velocities and accelerations
\item Inward pass (tip to base)\+: Propagate forces, compute joint torques
\end{DoxyEnumerate}

Mathematical Foundation\+: The RNEA solves the equation\+: τ = H(q)q̈ + C(q,q̇) + G(q) where\+:
\begin{DoxyItemize}
\item H(q)\+: Joint space inertia matrix
\item C(q,q̇)\+: Coriolis and centrifugal forces
\item G(q)\+: Gravity forces (not implemented, add external forces)
\end{DoxyItemize}
