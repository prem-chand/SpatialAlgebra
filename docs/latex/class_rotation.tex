\doxysubsection{Detailed Description}
Class for handling 3D rotations with multiple representations. 

The \doxylink{class_rotation}{Rotation} class extends Eigen\+::\+Matrix3d to provide a robust interface for working with 3D rotations. It maintains the underlying rotation matrix representation while offering convenient conversions to and from other common rotation representations.

Key features\+:
\begin{DoxyItemize}
\item Automatic handling of rotation composition
\item Conversion between different rotation representations
\item Vector transformation operations
\item Proper handling of rotation inverse and transpose
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
When constructing from matrices, the input should be a valid rotation matrix. The class does not currently enforce orthogonality or proper determinant. 
\end{DoxyWarning}
