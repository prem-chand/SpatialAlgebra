# Milestone v1.0: MVP / Core Library

**Status:** ✅ SHIPPED 2026-05-16
**Phases:** 1-10
**Total Plans:** 25

## Overview

Initial spatial vector algebra library implementation covering all core classes: 6D spatial vectors (twists/wrenches), rotation matrices, packed lower-triangular matrices, Plücker coordinate transforms, rigid body and articulated body inertias, forward dynamics (ABA), inverse dynamics (RNEA), comprehensive test infrastructure, integration tests, and documentation.

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- Use GTest framework from Phase 1 instead of bare assert() — better test reporting
- Fix MotionVector::crossMotion bug immediately upon discovery — critical for downstream correctness
- Remove Eigen 5.x version pin for Homebrew compatibility
- Cross-product operations delegate to canonical free functions in SpatialUtils.h
- Featherstone (2008) Algorithm 7.3 for ABA, Algorithm 7.1 for RNEA
- Separate Link structs (ForwardDynamicsLink, InverseDynamicsLink) to avoid POSIX conflicts
- Comprehensive GTest with property-based tests for mathematical invariants
- Doxygen EXTRACT_ALL=NO to require explicit documentation

**Issues Resolved:**

- Eigen 5.x compatibility (version pin removed)
- MotionVector::crossMotion incorrect formula (linear.cross → angular.cross + linear.cross)
- ForceVector::crossMotion and crossForce incorrect formulas
- Missing Rotation::operator*(Matrix3d) implementation
- LowerTriangular operator* ambiguity with Vector3d
- M*L friend operator loop bounds and indexing bug
- Link struct naming conflict with POSIX `link()` system call

**Issues Deferred:**

- PLX-04: tformABI() formula needs correction per Featherstone Eq 7.16 (→ v1.1, Phase 11)
- PLX-06: invtformABI() formula needs derivation and verification (→ v1.1, Phase 11)
- BF-02: Multi-link RNEA↔ABA consistency for 3+ link chains (→ v1.1, Phase 12)
- TST-07: Multi-link round-trip consistency test failures (→ v1.1, Phase 12)

**Technical Debt Incurred:**

- Rotation class is in global namespace, not SpatialAlgebra — inconsistency with other classes
- ABI transform formulas need verification against Featherstone Eq 7.16
- RNEA/ABA bias acceleration conventions need alignment for multi-link chains
