  <implementation>
    Integration test pattern:
    1. Setup identical kinematic tree in both ForwardDynamics and InverseDynamics
    2. Round-trip ABA→RNEA:

       - ForwardDynamics.computeAccelerations(tau)

       - Start with random tau
       - ABA.computeAccelerations(tau) → qddot
       - tau2 = RNEA.computeTorques(qddot)
       - Verify: tau2 ≈ tau
    4. Use EPSILON = 1e-8 for floating point tolerance
  </implementation>
