<task type="auto">
  <name>Task 2: Implement RNEA algorithm in InverseDynamics.cpp</name>
  <files>src/InverseDynamics.cpp</files>
  <action>
    Implement following Featherstone Algorithm 7.1:
    
    **outwardPass():** For i=0 to n-1:
    - if parent==-1: v = S*qdot, a = S*qddot
    - else: v = X.inverseTransformMotion(v_parent) + S*qdot
            a = X.inverseTransformMotion(a_parent) + S*qddot + cross(v, S)*qdot
    
    **inwardPass():** For i=n-1 to 0:
    - f = I.apply(a) + cross(v, I.apply(v))  (spatial force = inertia*accel + bias)
    - if child exists: f += X.transformForce(f_child)
    - tau = f.dot(S)  (project force onto joint axis)
    
    Follow ForwardDynamics.cpp style: error checking, const references, clear comments.
  </action>
