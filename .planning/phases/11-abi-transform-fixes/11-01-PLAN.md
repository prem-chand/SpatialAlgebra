    **Current implementation analysis:**
    The current tformABI() at line 104-128 uses:
    - `Y = H - M.getFullMatrix() * skew(translation)`  // Y = H - M*r̂
    - `I_new = R * (I - H^T*r̂ + r̂*Y) * R^T`
    
    **Problem identification:**
    The issue is in how the coupling matrix H transforms. According to Featherstone's spatial vector algebra:
    - For a 6x6 spatial transform X = [R, 0; -R*r̂, R], the inertia transform is I' = X * I * X^T
    - The articulated body inertia in 6x6 form is: Ia = [I, H; H^T, M]
    
    **Correct formula derivation:**
    X * Ia * X^T where X = [R, 0; -R*r̂, R] gives:
    ```
    [R, 0; -R*r̂, R] * [I, H; H^T, M] * [R^T, -r̂^T*R^T; 0, R^T]
    
    Top-left (I'): R*I*R^T + H*(-r̂^T*R^T) + 0*... 
                 = R*I*R^T - H*r̂^T*R^T
    ... (need full block matrix multiplication)
    ```
    
    **Action steps:**
    1. Write out the full 6x6 block matrix multiplication for X * Ia * X^T
    2. Compare with current implementation line-by-line
    3. Identify the exact formula discrepancy
    4. Document the correct formula in a comment before the implementation

  <action>
    Update invtformABI() implementation (lines 130-166) with the correct inverse formula.
    
    **Inverse transform principle:**
    If forward transform is I' = X * I * X^T, then inverse is I = X^{-1} * I' * X^{-T}
    
    For Plücker transform X = [R, 0; -R*r̂, R]:
    - X^{-1} = [R^T, 0; r̂*R^T, R^T] (note: translation becomes -R^T*t in Plücker coordinates)
    
    **Implementation approach:**
    1. Use inverse transform parameters: R_inv = R^T, t_inv = -R^T*t
    2. Apply the same tformABI formula with inverse parameters
    3. Alternatively, derive the closed-form inverse formula
    
    **Implementation pattern:**
    ```cpp
    ArticulatedBodyInertia PluckerTransform::invtformABI(const ArticulatedBodyInertia &Ia) const {
        // Use inverse transform: X^{-1} * Ia * X^{-T}
        // Inverse Plücker transform has: R_inv = R^T, t_inv = -R^T*t
        const Matrix3d& R = static_cast<const Matrix3d&>(rotation);
        Matrix3d R_inv = R.transpose();
        Vector3d t_inv = -R_inv * translation;
        Matrix3d t_inv_skew = skew(t_inv);
        
        auto M = Ia.getM();
        auto H = Ia.getH();
        auto Inertia = Ia.getInertia();
        
        // M' = R^T * M * R
        lt M_new = LowerTriangular::fromFullMatrix(R_inv * M.getFullMatrix() * R);
        
        // H' = R^T * (H - M * t_inv_skew) * R
        Matrix3d H_new = R_inv * (H - M.getFullMatrix() * t_inv_skew) * R;
        
        // I' = R^T * (I - H^T*t_inv_skew + t_inv_skew*H - t_inv_skew*M*t_inv_skew) * R
        Matrix3d I_full = Inertia.getFullMatrix();
        Matrix3d I_new_full = R_inv * (I_full - H.transpose()*t_inv_skew + t_inv_skew*H - t_inv_skew*M.getFullMatrix()*t_inv_skew) * R;
        lt I_new = LowerTriangular::fromFullMatrix(I_new_full);
        
        return ArticulatedBodyInertia(I_new, H_new, M_new);
    }
    ```
    
    **Critical:** The current implementation uses `Rt = R * translation` which is incorrect for the inverse transform.
