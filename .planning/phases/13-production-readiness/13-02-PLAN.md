<objective>
Add gravity support to both forward dynamics (ABA) and inverse dynamics (RNEA) via optional `gravity` parameter, defaulting to zero for backward compatibility. Gravity is implemented as base link acceleration per Featherstone formulation (D-07, D-08).

**Purpose:** Enable robots to compute dynamics under gravity — essential for all practical robotics applications. Prior to this fix, gravity could only be approximated via external forces.
**Output:** Gravity-aware computeAccelerations() and computeTorques() that accept `Vector3d gravity` param with zero default.
</objective>
