    - Outward pass iterates links from base (0) to tip (n-1)
    - Computes: v[i] = X[i].inverse().transformMotion(v[parent]) + S[i]*qdot[i]
    - Computes: c[i] = cross(v[i], S[i]) * qdot[i] (Coriolis/centrifugal terms)
    - Base link has v[0] = S[0]*qdot[0], c[0] = 0
  </behavior>
  <action>
Create `src/ForwardDynamics.cpp` implementing outward pass:

```cpp
void ForwardDynamics::outwardPass() {
    for (int i = 0; i < links.size(); i++) {
        int parent = links[i].parent;
        
        if (parent == -1) {
            // Base link: velocity from joint only
            links[i].v = links[i].S * links[i].qdot;
            links[i].c = MotionVector(Vector3d::Zero(), Vector3d::Zero());
        } else {
            // Propagate velocity from parent
            MotionVector vParent = links[parent].v;
            PluckerTransform X = links[i].X;
            
            // v[i] = X^{-1} * v[parent] + S[i] * qdot[i]
            links[i].v = X.inverseTransformMotion(vParent) + links[i].S * links[i].qdot;
            
            // c[i] = v[i] × S[i] * qdot[i] (Coriolis/centrifugal)
            // Using SpatialVector cross product: cross(v, S)
            links[i].c = cross(links[i].v, links[i].S) * links[i].qdot;
        }
    }
}
```

Reference: Featherstone (2008) Algorithm 7.3, Eq 7.17-7.18.

  <behavior>
    - Inward pass iterates links from tip (n-1) to base (0)
    - Computes: Ia[i] = I[i] + sum of transformed child articulated inertias
    - Computes: pa[i] = f[i] + sum of transformed child bias forces
    - Joint acceleration: qddot = (tau - S^T*Ia*S*qddot - S^T*pa) / (S^T*Ia*S)
  </behavior>

**inwardPass()** (Featherstone Algorithm 7.3):
```cpp
void ForwardDynamics::inwardPass(const Eigen::VectorXd& tau) {
    for (int i = links.size() - 1; i >= 0; i--) {
        // Initialize with rigid body inertia
        links[i].Ia = links[i].I;
        links[i].pa = links[i].f;  // f = I*v + bias terms
        
        // Compute bias force: f = Ia*c + external forces
        links[i].pa = links[i].Ia.apply(links[i].c);
        
        // Propagate to parent
        int parent = links[i].parent;
        if (parent != -1) {
            PluckerTransform X = links[i].X;
            // Transform articulated inertia to parent frame
            ArticulatedBodyInertia IaTransformed = X.tformABI(links[i].Ia);
            links[parent].Ia = links[parent].Ia + IaTransformed;
            
            // Transform bias force
            ForceVector paTransformed = X.transformForce(links[i].pa);
            links[parent].pa = links[parent].pa + paTransformed;
        }
    }
}
```

**computeAccelerations()**:
```cpp
void ForwardDynamics::computeAccelerations(const Eigen::VectorXd& tau) {
    outwardPass();
    inwardPass(tau);
    
    // Solve for joint accelerations
    for (int i = links.size() - 1; i >= 0; i--) {
        // qddot = (tau - S^T * pa) / (S^T * Ia * S)
        MotionVector IaS = links[i].Ia.apply(links[i].S);
        double denom = links[i].S.getAngular().dot(IaS.getAngular()) + 
                       links[i].S.getLinear().dot(IaS.getLinear());
        double numer = tau[i] - (links[i].S.getAngular().dot(links[i].pa.getAngular()) + 
                                  links[i].S.getLinear().dot(links[i].pa.getLinear()));
        links[i].qddot = numer / denom;
    }
}
```

Reference: Featherstone (2008) Algorithm 7.3, Eq 7.23-7.28.
