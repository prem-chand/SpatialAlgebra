| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering | FetchContent googlebenchmark download | mitigate | Pinned GIT_TAG v1.9.5 ensures immutable version; HTTPS GIT_REPOSITORY URL provides TLS transport security. Subsequent builds use local CMake cache — no repeated network fetch. |
| T-16-02 | Elevation of Privilege | Google Benchmark build system execution | accept | Google Benchmark is a well-established project (10k+ stars, 340+ contributors, Apache 2.0, first release 2013). | T-16-SC | Tampering | cmake -B build (no package manager installs) | mitigate | No packages installed via npm/pip/cargo in this phase. FetchContent pulls from GitHub HTTPS with pinned tag. No slopcheck concerns — Google Benchmark v1.9.5 is a verified OSS project. |
