<objective>
Restructure the ABA inward pass from a 3-phase design (initialize → partial qdd with condensation → correct qdd) to a single tip-to-base sweep per Featherstone Algorithm 7.3, where each link's qddot is computed as the final value and condensation removes the joint DOF before passing to the parent.

**Purpose:** Fix forward dynamics for chains with 3+ joints. The current 3-phase approach computes a "partial" qddot assuming zero parent acceleration, then corrects it in a separate forward pass. This correction is algebraically inexact for chains deeper than 2, causing all multi-link round-trip consistency tests to fail. The single sweep eliminates the correction step entirely — qddot is solved once, correctly, and spatial accelerations follow in a separate forward pass.

**Output:** Restructured `inwardPass()` producing correct qddot for 3+ link chains. The 3 existing multi-link consistency tests (ThreeLinkSerialChain, BranchingYConfiguration, TwoLinkRoundTripWithGravity) go from FAIL to PASS. The 2 existing condensation tests (CondensationReducesInertiaNorm, ThreeLinkSingleTorque) already exist and will now pass. Zero changes to `include/` headers.
</objective>

**Current inwardPass() 3-phase structure** (src/ForwardDynamics.cpp:82-179):

Phase 1 (lines 84-102): Initialize Ia and pa from rigid body inertia. Correct — keep.

Phase 2 (lines 104-158): Tip-to-base sweep. For each link:
  - Save Ia_unc[i] and compute D[i]
  - Compute partial qddot = (tau - S^T*pa) / D (assumes a_parent = 0)
  - Condense Ia (subtract joint DOF) and condense pa (add Ia*S*qdd)
  - Transform condensed Ia/pa and add to parent

Phase 3 (lines 160-179): Base-to-tip forward pass. For each link:
  - Compute a_prime = X*a_parent + c
  - correction = S^T * Ia_unc * a_prime
  - qddot = qddot_partial - correction / D
  - a = a_prime + S*qdd

**Bug:** The Phase 3 correction `S^T * Ia_unc * (a_parent + c)` algebraically over-corrects. The term `S^T * Ia_unc * c` is already included in `pa` (initialized as `Ia*c + cross(v, Ia*v) + f` in Phase 1), so it gets subtracted twice. The single sweep eliminates this by computing qddot from the fully accumulated Ia/pa only — no correction needed.
