<objective>
Restructure the ABA `inwardPass()` from the current 3-phase design (init → partial qddot + condensation → Phase 3 correction) to a single tip-to-base sweep with condensation per Featherstone Algorithm 7.3. The restructuring eliminates the Phase 3 correction bug (SC3) and fixes the pa initialization ordering (SC5). After the fix, all 4 new/updated non-zero COM tests from Plan 14-02 will turn GREEN, and all 11 test executables will pass the full regression suite (SC4).

**Purpose:** The current 3-phase inwardPass in `ForwardDynamics.cpp` computes partial qddot assuming zero parent acceleration (line 128: "This is a PARTIAL acceleration"), then applies a Phase 3 correction. This correction algebraically subtracts the term `S^T * Ia_unc * c` which is already included in `pa` (initialized as `Ia*c + cross(v, Ia*v) + f`), causing double-subtraction for non-zero COM chains. The single sweep eliminates this entirely — qddot is the FINAL answer computed from fully accumulated Ia/pa.

**Output:** Restructured `inwardPass()` with single sweep. All non-zero COM tests pass. Doxygen updated. Full regression green.
