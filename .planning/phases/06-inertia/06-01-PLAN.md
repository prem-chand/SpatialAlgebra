  <name>Task 1: Implement ArticulatedBodyInertia::apply() method</name>
  <files>include/ArticulatedBodyInertia.h</files>
  <action>
    Define the inline apply() method in the header file. The formula from the header comment is:
    f = Ia * v = [Iω + Hv; Hᵀω + Mv]
    
    Where:
    - I = Inertia (lt matrix)
    - H = coupling matrix (Eigen::Matrix3d)
    - M = mass matrix (lt matrix)
    - ω = angular component of motion vector
    - v = linear component of motion vector
    
    Implementation:
    1. Extract omega and v from mv using mv.getAngular() and mv.getLinear()
    2. Compute Iω = Inertia * omega
    3. Compute Hv = H * v
    4. Compute Hᵀω = H.transpose() * omega
    5. Compute Mv = M * v
    6. Torque = Iω + Hv
    7. Force = Hᵀω + Mv
    8. Return ForceVector(torque, force)
    
    Add the complete inline definition replacing the declaration at line 185.
  </action>
  <verify>
    <automated>cmake --build build 2>&1 | grep -i "error" | wc -l</automated>
